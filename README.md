# Via Fox Tour (React + Vite)

Landing page da Via Fox Tour construída com React e Vite.

## Como abrir no VS Code

1. Extraia o arquivo ZIP em uma pasta no computador.
2. No VS Code, use **Arquivo > Abrir Pasta** e escolha a pasta `via-fox-tour`.
3. No terminal integrado do VS Code, execute `npm install` uma única vez.
4. Depois execute `npm run dev` e abra o endereço exibido no terminal.

Os arquivos principais estão em `src`:

- `App.jsx` — reúne as seções da página e os componentes;
- `main.jsx` — inicia o React;
- `styles.css` — cores, layout e responsividade;
- `public/assets/` — logo e fotos dos destinos.

Para gerar a versão final de produção, execute `npm run build`.
